# AGENTS.md

Vendor-agnostic context for any AI coding agent working on **ias-agent-skills**.
This is the single source of truth. Every vendor (Claude Code, Codex, Cursor, …)
reads this file; Claude reads it via the generated `CLAUDE.md` shim.

## What this repo is

Agent skills that teach an AI agent how to integrate and use the
[InAppStory](https://inappstory.com) (IAS) SDK across Android, iOS, React Native,
JavaScript, React and Flutter. See `README.md` for the full picture.

## Layout

```
skills/<skill-name>/SKILL.md   # the product: published IAS skills (checked in)
.agents/                       # agent config, source of truth
  setup                        # compiles .agents/ into vendor folders
  shared/                      # payload mirrored into every vendor dir
AGENTS.md                      # this file
CLAUDE.md, .claude/, .codex/   # GENERATED, gitignored — do not edit
```

## Working rules

- **Vendor folders are read-only.** `.claude/`, `.codex/`, `.cursor/` and
  `CLAUDE.md` are generated by `.agents/setup`. Edit `.agents/` (or this file)
  instead and rerun setup — hand edits to vendor folders get overwritten.
- Skills follow the standard agent-skill format: a `SKILL.md` with frontmatter
  plus supporting files, one directory per skill. Author new ones with the
  `skill-creator` skill.
- Skills are grounded in the IAS SDK docs (<https://git.kiozk.ru/story/docs.git>).
  Don't invent SDK behavior — cite the docs.

## Bootstrap

Fresh clone, once:

```bash
bash .agents/setup
```

Claude reruns it automatically on session start.
